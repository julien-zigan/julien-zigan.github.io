Laufzeit (Kartesisches Produkt)

# kartesisches_produkt.py
def cart_product(a, b):
    prod = []
    for x in a:
        for y in b:
            prod.append((x, y))
    return prod
result = cart_product([1, 2, 3], ['A', 'B'])
print(result)

Warum ist das der Worst Case?

Für jede Eingabe I = (a, b) mit den Längen (n, m) gilt: T(I) = n · m. Die Werte und ihre Reihenfolge ändern die Anzahl der Aufrufe nicht.

Das Maximum über alle Eingaben dieser Größe ist deshalb ebenfalls T(n, m) = n · m.

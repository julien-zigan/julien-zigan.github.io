# kartesisches_produkt.py
result = cart_product([1, 2, 3], ['A', 'B'])
def cart_product(a, b):
    prod = []
    for x in a:
        for y in b:
            prod.append((x, y))
    return prod
print(result)

Warum ist das der Worst Case?

Für jede Eingabe I = (a, b) mit den Längen (n, m) gilt: Tcart_product(I) = n · m. Die Werte und ihre Reihenfolge ändern die Anzahl der Aufrufe nicht.

Das Maximum über alle Eingaben dieser Größe ist deshalb ebenfalls Tcart_product(n, m) = n · m.
